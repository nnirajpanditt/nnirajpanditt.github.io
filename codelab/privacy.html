This Privacy Policy explains how CodeLab — Python IDE & Compiler ("CodeLab", "we", "our", or "us"), developed by Niraj AI Solutions (Legal Entity: Niraj Kumar), handles, stores, and protects user information when you use our mobile application (Application ID / Package Name: com.codelab.compiler.editor).

2. Information We Collect and Process

A. Locally Stored Data (On Your Physical Device)

The core execution and editing functionality of CodeLab operates entirely on your physical device. This includes:

  • Python Source Files: All .py scripts, project workspaces, and files you create, edit, or import remain strictly within your device storage.
  • Interactive Terminal Logs & Outputs: Console logs, execution results, error tracebacks, and program outputs stay on your phone.
  • Learning Curriculum Progress: Completed lesson checkpoints and practice code files.
  • Editor Preferences: Syntax themes, font size, indentation preferences (tabs/spaces), word wrap, and line number toggles.

B. Zero Personal Data Tracking

We do not collect names, phone numbers, contacts, GPS location, device serial numbers, or biometric information. CodeLab requires no user registration, no account creation, and no mandatory login to code, compile, or debug Python.

3. Android Permissions & Justification

CodeLab requests the absolute minimum permissions necessary to function:

  • android.permission.INTERNET: Required only if you explicitly choose to install pure Python packages from PyPI (Python Package Index) or access online Python documentation. The code editor, local Python compiler engine, console, and 20-lesson interactive academy operate 100% offline without network connectivity.
  • android.permission.ACCESS_NETWORK_STATE: Used solely to detect whether an active Wi-Fi or cellular network exists before attempting a package download from PyPI, providing friendly offline alerts instead of socket timeouts.
Storage Access Framework: CodeLab follows modern Android 10+ Scoped Storage guidelines. It requires ZERO broad storage permissions (such as MANAGE_EXTERNAL_STORAGE) and interacts with project directories securely via the system Storage Access Framework (SAF).

4. Third-Party Services & Telemetry

CodeLab does not include advertising SDKs, ad trackers, or third-party behavioral analytics brokers. External requests only occur when you explicitly initiate an action, such as downloading a wheel package from pypi.org.

5. Data Retention and Deletion

Because all files, workspaces, and preferences reside on your physical device, you retain absolute ownership and control over your data. Deleting a file or project permanently removes it from your device. Uninstalling the app permanently purges all local app data and caches. For more information, visit our Data Deletion Policy.

6. Children's Privacy

CodeLab is an educational and productivity programming tool designed for students, computer science learners, and developers. We do not knowingly collect or solicit personal information from children under 13 years of age. If you believe any minor has provided personal data, please contact us immediately for prompt removal.

7. Security

We implement strict Android security best practices. Code execution occurs within isolated Android process sandboxes. All external requests for package installation use encrypted HTTPS (TLS) connections.
