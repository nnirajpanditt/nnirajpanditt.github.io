Frequently Asked Questions (FAQ)

Q1: Does CodeLab require an internet connection to run Python code?

No! CodeLab features a complete local Python compiler engine built directly into the app. You can write, run, debug, and test Python code with zero internet connection anywhere, anytime.

Q2: How does the interactive input() function work?

When your Python code executes input("Prompt: "), the output panel pauses and activates the interactive input bar at the bottom. Type your input and press Send (↵) to feed the text directly into your script stream in real time.

Q3: Why am I getting an IndentationError?

Python strictly enforces block indentation:

  • Standard indentation is 4 spaces or 1 tab per block level.
  • Never jump 2, 3, or 4 tabs for a single block (e.g. immediately after an if statement).
  • Never mix tabs and spaces in the same file.

Q4: Can I install packages with pip?

Yes! Pure Python packages available on PyPI (such as requests, urllib3, sympy, six) can be installed via the in-app Package Manager. Packages requiring C/C++ compilation need pre-built Android wheels.

Q5: Where are my Python files saved?

Your files are stored in your app workspace or in your chosen Android folder via the Storage Access Framework (SAF). You can export and share scripts anytime using standard file sharing.
