Data Deletion Policy

Google Play Compliance • Effective Date: September 14, 2026

This page describes how data deletion operates in CodeLab — Python IDE & Compiler (com.codelab.compiler.editor) in accordance with Google Play's User Data policy.

100% User-Controlled Local Data: CodeLab does not operate external cloud accounts or store your personal files on remote servers. All your project code, logs, and settings are stored strictly on your local device.

How to Delete Your Data

Option 1: Deleting Individual Files or Projects

You can delete any Python file, workspace, or project directly within the application:

  1. Open the side file drawer or project manager in CodeLab.
  2. Swipe or tap the 3-dot options menu next to any file or folder.
  3. Select Delete. The file is immediately and permanently purged from your device storage.

Option 2: Clearing All Application Data and Workspaces

To erase all Python scripts, saved caches, and editor configurations completely:

  1. Open your Android device's Settings.
  2. Navigate to Apps → CodeLab.
  3. Tap Storage & Cache → Clear Storage (Clear Data).
  4. All local project files, preferences, and caches will be instantly and permanently deleted.

Option 3: Complete App Uninstallation

Uninstalling CodeLab from your device permanently removes the entire application sandbox, including all internal files, settings, and caches.
